# Source evaluation

Score each important source quickly on five dimensions (high / medium / low):

1. **Authority** — Is the publisher the primary owner of the information (the vendor for its own pricing, the regulator for its rules, the authors for their study)?
2. **Recency** — Is it current for the question? Note publication date and product/version.
3. **Independence** — Does the source benefit from the claim (vendor benchmarks, sponsored content, affiliate reviews)?
4. **Evidence** — Does it show methodology, data or reproducible detail, or only assertions?
5. **Corroboration** — Do independent sources agree?

## Resolving conflicts
- Prefer primary + recent + independent evidence.
- If two credible sources still disagree, report both values with their context (date, method, scope) and explain which you would rely on and why.
- Vendor claims about their own product's performance are "claimed", not "established", unless independently reproduced.

## Wording guide
- Established: multiple independent, credible sources agree.
- Reported: a single credible source.
- Claimed: self-interested or unverified source.
- Unknown: no credible source found — say so explicitly.
