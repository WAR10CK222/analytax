# Executive summary structure

## Bottom line up front (BLUF)
The first one or two sentences answer the client's question or state the recommendation. A reader who stops there must still get the answer.

## Then, in order
1. **Key points** — 3–5 bullets, each a complete claim with a citation where relevant.
2. **Evidence / detail** — tables or short sections only as needed to support the key points.
3. **Caveats** — only material limitations (skip if none).
4. **Next steps** — only if the client asked for a recommendation or plan.

## Sizing
| Requested length | Target |
|---|---|
| short | ≤ 150 words, no headings |
| medium | 150–500 words, bold lead-ins or 2–3 headings |
| long | 500–1500 words, headings, tables allowed |

## Rules
- No process narration ("we researched…", "task 3 found…").
- No repetition between BLUF and key points — key points add support, not restatement.
- Numbers keep their units, dates and sources.
