# Critique rubric

Assess each dimension and record issues with a severity.

| Dimension | Question |
|---|---|
| Goal fit | Does it directly answer what the client asked, in the requested format and length? |
| Correctness | Are claims supported by the cited sources? Any contradictions with upstream findings? |
| Completeness | Is anything the acceptance criteria or the client's goal requires missing? |
| Reasoning | Do conclusions follow from the evidence? Are assumptions stated? |
| Clarity | Can the audience understand it on first read? Is the answer up front? |
| Actionability | Can the client act on it (clear recommendation, conditions, next steps if asked)? |

## Severity
- **Blocker** — wrong, unsupported on a key point, or fails the client's question. Must be fixed.
- **Major** — materially weakens the result (missing important comparison, unclear recommendation).
- **Minor** — polish. Mention at most three; never request a revision for minors alone.

## Requesting a revision
Write revision instructions as a numbered checklist of concrete changes ("Replace the 2023 throughput figure with the 2026 benchmark from [3]"), not vague advice ("improve accuracy"). Include everything needed so the writer does not have to re-read your review.
